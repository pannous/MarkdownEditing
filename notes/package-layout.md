# Package layout (one Markdown plugin)

- `Packages/MarkdownEditing` (this repo, pannous/MarkdownEditing) is the complete package.
  Package Control's `Installed Packages/MarkdownEditing.sublime-package` was removed (2026-09-30);
  don't reinstall it, it would shadow nothing but reintroduce stale files.
- `Installed Packages/Markdown.sublime-package` is generated by `plugins/bootstrap.py`
  (`augment_default_markdown`) from `syntaxes/` to override ST's built-in Markdown package.
  It is rewritten on plugin load whenever it differs from `syntaxes/`, so never edit it by hand.
  It used to be generated once and never refreshed -> stale MultiMarkdown/Markdown syntaxes.
- One `WikiPage`: root `wiki_page.py`. `plugins/wiki_page.py` (mde_* commands, F12) imports it;
  `open_url.py` / `open_page.py` (mouse clicks) use it too.
- User settings (`Packages/User/Markdown.sublime-settings`, `Preferences.sublime-settings` syntax_map,
  `md_syntax_enforcer.py`) point at `Packages/MarkdownEditing/syntaxes/MultiMarkdown.sublime-syntax`.
- Other markdown packages: MarkdownLink, MarkdownPreview are in ignored_packages;
  MarkdownLivePreview and Markdown HTML Preview are previewers only (no syntax/wiki overlap).
- Probes: `python3 probes/test_*.py` (stub `sublime`, run outside ST).
